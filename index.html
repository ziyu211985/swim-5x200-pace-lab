Calculation basis. Swimming New Zealand competition tables historically specify +6.80 s when converting 400 m freestyle from 25 m to 50 m; this tool therefore uses −6.80 s for LCM→SCM. The 5×200 protocol uses the fifth-stage velocity from the swimmer’s 400 m front-crawl reference, with four successive 0.05 m·s⁻¹ decrements. A recent 25 m-pool implementation used 3 min passive recovery and an optional 0.83 s per-turn adjustment when a respiratory snorkel was used.
